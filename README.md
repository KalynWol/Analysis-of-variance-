# Analysis-of-variance-
Analysis of precipitation variation for Buffalo and San Diego since 1941
This file distributs the sample data into 3 main periods and then runs ANOVA, Kruskal-Wallis, and Median tests to interpret whether there is significant climate changes for either city. 
Using Rstudio to run each test satrting with ANOVA, then Kuskal-Wallis, then Median test and finally the Chi-Square test. I derived results (p-values) from each test to support my findings.
San Diego has no evidence for climate change, however there is some subtle changes throughout the years in Buffalo that may point to slight change in climate. However I did not see it as enough to intepret STRONG evidence for climate change in Buffalo. 
The main tools are RStudio and GitHUb
I have never lived in San Diego but my experience with Buffalo weather is that it is very spotty and can change very quickly year to year and even day to day at times. This supports my interpretation of the results for Buffalo.
